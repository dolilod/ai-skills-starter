# Mulai latihan tanpa Terminal

1. Buka [ai-skills-starter di GitHub](https://github.com/dolilod/ai-skills-starter) di browser. Klik **Code** → **Download ZIP**. Atau unduh langsung [berkas ZIP](https://github.com/dolilod/ai-skills-starter/archive/refs/heads/main.zip).
2. Buka **Downloads** di Finder, lalu klik dua kali berkas ZIP untuk mengekstraknya. Buka folder hasil ekstraksi.
3. Buka folder **contoh** dan cari folder untuk video yang ingin diikuti:

   | Folder | Video |
   | --- | --- |
   | `ep6-reviu-dokumen` | Reviu dokumen masuk |
   | `ep8-rab` | Menyusun dan mereviu RAB |
   | `ep10-paket-usulan` | Paket usulan lengkap |
   | `ep11-cad-freecad` | Model CAD bordes dan railing |
   | `ep14-notulen` | Catatan rapat jadi daftar tindak lanjut |
   | `ep15-instruksi-palsu` | Cek instruksi palsu dalam dokumen |
   | `ep16-kebutuhan-bahan` | Kebutuhan bahan operasional |
   | `ep17-rekap-csv` | Rekap pengeluaran dari CSV |
   | `ep18-opsi-keputusan` | Susun pilihan untuk keputusan tim |
   | `ep19-subagent` | Bagi tugas ke subagent di DeepSeek Harness |

4. Di Finder, buka **Documents** dan buat folder **Latihan-AI**. Salin folder contoh yang dipilih ke dalamnya; Anda boleh mengganti nama salinannya, misalnya menjadi `Documents/Latihan-AI/reviu-dokumen`. Gunakan folder salinan ini untuk latihan agar berkas contoh asli tetap tersedia.
5. Di DeepSeek Harness, pilih **Add workspace** → pilih folder latihan yang baru disalin → pilih model.
6. Data dalam `contoh` bersifat fiktif. Jangan masukkan dokumen asli atau rahasia ke folder latihan.

Berkas *skill* ada di folder `skills/`. Pengguna Terminal tetap dapat memakai `git clone` seperti dijelaskan di [README](README.md).
